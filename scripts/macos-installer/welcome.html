Welcome to Stellar VPN

One installation for the app and its network helper.

Before updating: quit Stellar VPN. This installer will stop if the app is still open.

macOS will request administrator approval to install a persistent, privileged system helper. Only your active macOS user can control it. A local firewall check may briefly interrupt network connections. It does not inspect browsing history or contact an external test service.

After installation, open Stellar VPN in Applications and sign in with Stellar ID or an anonymous account number. The app uses your Mac's language initially and checks the helper in the background. You can change the language in Settings.

Unsigned local test package. Signing and notarisation are not included. This is not a public release. No macOS security protections will be disabled.
