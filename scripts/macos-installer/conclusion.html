Open Stellar VPN

Open Applications → Stellar VPN and sign in.

The system helper is checked in the background. A repair screen appears only if it is missing, outdated or unavailable. If a check fails, quit the app, rerun the complete installation package and approve the macOS prompt. Then choose Try again.

Kill switch is available only when firewall verification passes. Login does not itself mean the VPN is connected.

To remove the app and helper, quit Stellar VPN and run the separate Stellar VPN Uninstall package. It removes only Stellar-owned network rules and files; local account data and preferences are kept.
